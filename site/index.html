Features

Knows what your agent is doing.
Feels how you're doing.

Atom reads Antigravity's own lifecycle hooks, so every state is real: no guessing, no polling your screen.

Moods that last the turn

Swear at your agent and Atom runs red with angry brows until the reply ends. Say thanks and it hops.

Sleeps on quota

When the active model hits its 5-hour or weekly limit, Atom dozes off. Switch models and it wakes at once.

Click to dance

Click Atom for a groove. Alt+click moves it to the other side of the prompt bar, Shift+click changes skin.

Skins and outfits

Atom V2 by default, plus the classic Atom, Cozy Chibi, base qt. and four Nobility Outfits that change with the model you pick.

Install

One command. Then reopen Antigravity.

You only need Python 3. Pick your system, run the installer, then quit Antigravity completely and open it again from Atom's launcher.

One-line install

curl -fsSL https://raw.githubusercontent.com/Arnav8452/atom/main/install.sh | bash

Then open Antigravity through Atom's launcher

Linux: the antigravity.desktop entry in your app menu. macOS: ~/Applications/Antigravity (Atom).app.

Uninstall

./install.sh --uninstall

One-line install (PowerShell)

irm https://raw.githubusercontent.com/Arnav8452/atom/main/install.ps1 | iex

Then open Antigravity through Atom's shortcut

Use Antigravity (Atom) in the Start Menu or on your Desktop.

Uninstall

.\install.ps1 -Uninstall

Clone and install

git clone https://github.com/Arnav8452/atom.git atom && cd atom
./install.sh          # Linux / macOS
.\install.ps1         # Windows PowerShell

No Git? Download the ZIP

Get main.zip, extract it to a folder you'll keep, and run ./install.sh or .\install.ps1 inside it.

Run without installing

From any clone or extracted folder, the launcher links the hooks plugin on first start.

python3 atom_launch.py

Update

Run the one-line installer again, or git pull inside your clone.

These manifests live in the repo's packaging/ folder. Run them from a clone.

Arch Linux (AUR / makepkg)

cd packaging/aur && makepkg -si && atom-setup

macOS (Homebrew)

brew install --HEAD ./packaging/homebrew/antigravity-atom.rb
"$(brew --prefix)/opt/antigravity-atom/libexec/install.sh"

Windows (Scoop)

scoop install .\packaging\scoop\antigravity-atom.json

Windows (Winget)

Manifest: packaging/winget/Arnav8452.AntigravityAtom.yaml

Already running Antigravity? Quit it completely first. Opening it again only forwards to the running window, and Atom won't attach.

Antigravity CLI

Atom in your terminal.

In agy, Atom sits in the status line right under the prompt and reacts to the same things: thinking, writing code, running commands, waiting for your OK, done, errors, moods and quota sleep.

Install

agy plugin install https://github.com/Arnav8452/atom
python3 ~/.gemini/config/plugins/atom/atom_cli_setup.py

Already have desktop Atom? The CLI shares its plugin, so only the second line is needed. From a clone: agy plugin install ./atom, then python3 atom/atom_cli_setup.py.

Activate

Setup adds Atom as agy's custom status line. Nothing else in your settings changes, and it won't replace a status line you already have. Quit agy and start it again to meet Atom.

Switch between the bar and the big Atom

In the empty prompt, type ! on its own. The prompt turns into a blue !, which is agy's shell mode. Then type atom-toggle and press Enter. No model is involved, and Atom remembers your choice.

Make it yours

Re-run setup with --skin atom, chibi or base-qt, with --style sprite to keep the CLI's own status line, or with --color 256 for older terminals. To turn it off: atom_cli_setup.py --uninstall.

Uses only what the CLI documents. Plugin hooks, the custom status line, and agy's own ! shell mode. Atom never wraps or injects into agy, and never stores your email, paths or prompts. Full guide: CLI.md.
