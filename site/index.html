atom

A tiny pixel companion that stands on the prompt bar in the Antigravity desktop app and reacts to what your agent is doing: reasoning, editing code, running commands, exploring files, or sleeping off a quota limit. It also lives in the status line of Antigravity CLI.

Star on GitHub Install Atom Atom for the CLI

19 states, drawn in code

Moods that last the turn

Swear at your agent and Atom runs red with tilted eyes until the reply ends. Thank it and it hops.

Sleeps on quota

When the active model hits its 5-hour or weekly limit, Atom dozes off. Switch models and it wakes at once.

Local only

Python 3 standard library, no pip installs, no telemetry, no network calls. It never stores your prompts.

Install

You only need Python 3. Pick your system, run one command, then quit Antigravity completely and reopen it from the new launcher.

One-line install

curl -fsSL https://raw.githubusercontent.com/Arnav8452/atom/main/install.sh | bash

Then open Antigravity through Atom's launcher

Linux: the antigravity.desktop entry in your app menu. macOS: ~/Applications/Antigravity (Atom).app.

Uninstall

./install.sh --uninstall

One-line install (PowerShell)

irm https://raw.githubusercontent.com/Arnav8452/atom/main/install.ps1 | iex

Then open Antigravity through Atom's shortcut

Use Antigravity (Atom) in the Start Menu or on your Desktop.

Uninstall

.\install.ps1 -Uninstall

Clone and install

git clone https://github.com/Arnav8452/atom.git atom && cd atom
./install.sh          # Linux / macOS
.\install.ps1         # Windows PowerShell

No Git? Download the ZIP

Get main.zip, extract it to a folder you'll keep, and run ./install.sh or .\install.ps1 inside it.

Run without installing

From any clone or extracted folder, the launcher links the hooks plugin on first start.

python3 atom_launch.py

Update

Run the one-line installer again, or git pull inside your clone.

Atom in your terminal

Atom also runs in Antigravity CLI (agy). It sits in the status line right under the prompt and reacts to the same things: thinking, writing code, running commands, waiting for your OK, done, errors, moods and quota sleep.

1. Install

agy plugin install https://github.com/Arnav8452/atom
python3 ~/.gemini/config/plugins/atom/atom_cli_setup.py

Already have desktop Atom? The CLI shares its plugin, so only the second line is needed. From a clone: agy plugin install ./atom, then python3 atom/atom_cli_setup.py.

2. Activate

Setup adds Atom as agy's custom status line. Nothing else in your settings changes, and it won't replace a status line you already have. It also installs the atom-toggle command. Quit agy and start it again to meet Atom.

3. Switch between the bar and the big Atom

In the empty prompt, type ! on its own. The prompt turns into a blue !, which is agy's shell mode. Then type atom-toggle and press Enter. Atom switches straight away. No model is involved, and Atom remembers your choice.

Skins and options

Atom V2 is the default. Re-run setup with --skin atom, chibi or base-qt, with --style sprite to keep the CLI's own status line, or with --color 256 for older terminals. Preview them all with python3 atom_status.py --demo --skin all.

Turn off

python3 ~/.gemini/config/plugins/atom/atom_cli_setup.py --uninstall
agy plugin uninstall atom   # only if you don't use desktop Atom

Uses only what the CLI documents. Plugin hooks, the custom status line, and agy's own ! shell mode. Atom never wraps or injects into agy, and never stores your email, paths or prompts. Full guide: CLI.md.
